# ‹M› RTU-Box (v3.2)
> **Автономный полевой сниффер, мастер, сканер шины и эмулятор Modbus RTU в одном HTML-файле.**

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Tech: Web Serial API](https://img.shields.io/badge/Tech-Web%20Serial%20API-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)
[![No Install](https://img.shields.io/badge/Setup-Zero%20Install%20(Single%20HTML)-brightgreen.svg)]()

**RTU-Box** — легковесный инструмент для инженера АСУ ТП, наладчика КИПиА и разработчика промышленных контроллеров. 

Приложение работает напрямую из браузера через **Web Serial API** и упаковано в **один монолитный HTML-файл**, который запускается даже с флешки на любом полевом ноутбуке без интернета.

---

## ⚡ Быстрый старт

1. Скачайте файл `RTU-Box V3.2.html`.
2. Откройте его в любом Chromium-браузере (**Google Chrome, Microsoft Edge, Opera, Brave**).
3. Воткните обычный USB-RS485 адаптер, нажмите **«Выбрать COM-порт (USB) и подключиться»** — и вы в эфире.

## 🛠 Ключевые возможности

### 🕵️ 1. Пассивный сниффер с «умным» парсером
* **Слушайте всю шину параллельно:** садитесь преобразователем прямо на клеммы `A+`/`B-` работающей сети и наблюдайте полный диалог между ПЛК и приборами.
* **Автоматическое разделение ролей:** парсер на лету отличает `[Запрос]` Мастера от `[Ответа]` Слейва по структуре кадра, даже если для адаптера весь трафик идет в `RX`.
* **Живая цветовая анатомия кадра:** подсветка `Slave ID`, кода функции, полезных данных и валидации суммы **CRC-16 Modbus (0xA001)**.
* **Декодирование на лету:** автоматический перевод регистров в `UINT16` и знаковый `INT16`, мгновенная детекция стандартных кодов ошибок (Exceptions `01..06`).
* **Экспорт:** выгрузка всего журнала перехваченных пакетов в `.CSV` одним кликом.

### 🎭 2. Конструктор карты регистров Slave (Имитатор приборов)
* **Работа без «железа»:** ПЛК в шкафу уже запрограммирован, а реальный частотник (ЧРП) или расходомер (УВП) еще не привезли? Ноутбук полностью заменит отсутствующее устройство.
* **Умный авто-перехват:** если контроллер обращается к адресу, которого еще нет в таблице, RTU-Box сам создаст строку, определит область памяти (`0x`–`4x`) и покажет, что именно запрашивает ПЛК.
* **Строгий стандарт Modbus Memory Areas:** жесткая промышленная классификация регистров (`0x Coils`, `1x Inputs`, `3x Input Registers`, `4x Holding Registers`).
* **Импорт / Экспорт CSV:** создавайте и редактируйте карты регистров прямо в Microsoft Excel.
* **Генератор технологического дрейфа:** имитируйте колебания реального расхода или давления по синусоиде (галочка «Др.»).
* **Стресс-тест алгоритмов ПЛК:** принудительная генерация аварийных ответов (`02 Bad Address`, `06 Slave Busy`) для проверки реакции аварийных защит в контроллере.

### 🔍 3. Сканер шины с автоперебором скорости (Auto-Baud)
* Не знаете, с какими сетевыми настройками прибор приехал со склада?
* Включите **Auto-Baud** — сканер сам на лету перенастроит COM-порт по выбранным скоростям (`9600..115200`) и четностям (`8N1`, `8E1`, `8O1`), найдет живой узел и предложит применить настройки порта в 1 клик.

### 🎮 4. Режим Мастера и автоопрос (Cyclic Polling)
* Ручная отправка одиночных команд чтения/записи с интерактивным предпросмотром кадра и авторасчетом CRC.
* Фоновый циклический опрос с контролем счетчиков `TX`, `Ответов OK` и `Таймаутов` (незаменимо для поиска плавающего дребезга контактов и помех от силовых кабелей).

### 🧮 5. Инженерный калькулятор адресов (Вкладка FAQ)
* **Modicon ⇄ Реальный адрес:** мгновенный перевод реального протокольного смещения (счет с `0`) в формат нотации Modicon (`40561`, `32001` — счет с `1`), принятый в DirectSOFT, Schneider Electric и SCADA-системах.
* **DirectLOGIC калькулятор:** перевод восьмеричных ячеек памяти контроллеров Koyo / DirectLOGIC (`V2000`, `X0`, `Y0`, `C0`) в десятичные адреса Modbus.

## 🔌 Физическое подключение (RS-485 2W)

Для пассивного прослушивания или эмуляции подключите USB-конвертер параллельно шине:

```text
 [ПЛК / Мастер]               [Прибор 1 (Slave 1)]        [Прибор N (Slave N)]
  (A+)  (B-)  (GND)            (A+)  (B-)  (GND)           (A+)  (B-)  (GND)
   │     │     │                │     │     │               │     │     │
===╪═════╪═════╪════════════════╪═════╪═════╪═══════════════╪═════╪═════╪=== Линия RS-485
   │     │     │                                           │     │     │
  ┌┴┐ 120 Ом   │                                          ┌┴┐ 120 Ом   │
  └┬┘ (Линия)  │                                          └┬┘ (Линия)  │
               │                                                       │
               └───────────────┬───────────────────────────────────────┘
                               │ (Экран / SG)
                               ▼
                          ┌─────────┐
                          │ A+   B- │  (USB-RS485 свисток)
                          └────┬────┘
                               │ USB
                          ┌────┴────┐
                          │ 💻 Ноут │  (RTU-Box в браузере)
                          └─────────┘
Ответвительный провод от магистрали до USB-свистка делайте коротким (до 1–1.5 м).
Дополнительный согласующий резистор 120 Ом на ноутбук не ставится.
